# Alok Pradhan Portfolio

Animated React portfolio upgraded with:

- GSAP 3 + ScrollTrigger for entrance choreography and scroll animations
- DOM based magnetic buttons, 3D tilt cards, custom cursor and scroll progress
- React Three Fiber + Three.js + Drei WebGL hero scene
- Animated 3D distorted core, orbiting rings and star field
- Responsive behavior and prefers-reduced-motion support
- Existing React/Tailwind/MUI sections and portfolio content preserved

## Run

```bash
npm install
npm run dev
```

## Main animation files

- `src/components/GSAPExperience.jsx`
- `src/components/ThreeHero.jsx`
- `src/components/Hero.jsx`
- `src/index.css`

The Three.js scene is decorative and does not replace the accessible HTML content.
